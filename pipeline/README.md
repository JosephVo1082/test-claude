# pipeline/

Nơi theo dõi cơ hội kinh doanh. File chính: `pipeline.md`.

- Cập nhật `pipeline.md` mỗi khi có thay đổi trạng thái cơ hội.
- Gõ `/pipeline` để agent rà soát: cơ hội đình trệ, SLA sắp trễ, ưu tiên tuần này.
- Gõ `/report` để agent tổng hợp báo cáo tiến độ cho CEO/BOD từ dữ liệu ở đây.

Có thể thay bằng `pipeline.xlsx` nếu muốn; giữ đúng các cột như trong `pipeline.md`.
